# rs-sensors

Терминальный монитор датчиков (TUI) на Rust, работающий поверх [libsensors](https://github.com/lm-sensors/lm-sensors) — той же библиотеки, что использует утилиту `sensors` из пакета `lm-sensors`.

В реальном времени (раз в секунду) показывает температуры, вентиляторы, напряжения, мощность, ток, энергию и влажность, с цветовыми индикаторами статуса (OK / WARN / ALARM) и графической шкалой для температур.

## Возможности

- Живое опросание всех доступных датчиков каждые 1 секунду
- Фильтр по типу: All / Temp / Fan / Power / Voltage / Current / Energy (клавиша `f`)
- Сортировка: по значению (по убыванию) или по порядку чипов (клавиша `s`)
- Подсветка статусов: зелёный OK, жёлтый WARN (за мин/макс), красный ALARM (за крит или флаг alarm)
- Текстовый режим для скриптов: `--list` / `-l` выводит один снимок в столбцы и выходит

## Зависимости

- Rust (edition 2024)
- C-компилятор (gcc/clang) — для сборки FFI-обёртки
- `libsensors` с заголовками (`liblsensors-dev` / `libsensors` с `include/sensors`)

Ключевые crate: `ratatui` (TUI), `crossterm` (ввод/терминал), `anyhow` (ошибки), `cc` (сборка C-обёртки в build-скрипте).

## Сборка

```sh
cargo build
```

## Запуск

TUI-режим:

```sh
cargo run
```

Один раз в текст:

```sh
cargo run -- --list
```

## Управление

| Клавиша | Действие |
|---|---|
| `q` | выход |
| `↑` / `↓` (и PgUp/PgDn, Home/End) | выбор строки |
| `f` | смена фильтра |
| `s` | переключение сортировки |
| `r` | принудительный refresh сейчас |
| `?` или `h` | справка |

## Структура проекта

- `src/main.rs` — TUI, модель датчиков, FFI, логика статусов
- `src/c/sensors_wrapper.c` — тонкая C-обёртка над `libsensors`
- `build.rs` — компиляция обёртки и линковка `-lsensors`
